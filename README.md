# 🎮 Basic Platformer with Kenney 2D Assets

A foundational 2D platformer game built with C# and Kenney's free 2D assets. This project serves as a confidence-building exercise and a game meant to be finished and polished.

---

## 📋 About

This is a passion project aimed at creating a fun, engaging platformer experience. It incorporates:
- **Classic platformer mechanics** - Jump, move, and navigate through levels
- **Kenney 2D assets** - Beautiful free sprite and tileset graphics
- **C# implementation** - Built with a focus on clean, understandable code

The goal is to complete this game from concept to a finished, playable product.

---

## 🎯 Features

- ✨ Smooth character movement and controls
- 🏃 Jump mechanics with physics-based gameplay
- 🎨 Colorful Kenney 2D sprite art and tilesets
- 🗺️ Multiple levels to explore and complete
- 🎵 Immersive 2D platformer experience
